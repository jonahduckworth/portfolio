# JD Builds Portfolio

Portfolio/company site for JD Builds.

## Stack

- Next.js
- TypeScript
- npm

## Commands

```bash
npm ci
npm run dev
npm run lint
npm run build
```

## Development

Start the local app:

```bash
npm run dev
```

Open `http://localhost:3000`.

## Verification

- Run `npm run lint` and `npm run build` before shipping content, route, or UI changes.
- For visual changes, check desktop and mobile layouts when practical.

See `AGENTS.md` for Codex/agent workflow guidance.
